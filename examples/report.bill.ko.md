**캐시 적중률 50.8%** — 입력 토큰 중 캐시에서 읽힌 비중입니다(AI 제공사 사용량 집계 기준). 자세한 것은 3절. 모델별로는 47.6% ~ 70.5% 입니다.

## 1. 분석 대상 — 입력 등급 D(AI 제공사 사용량 집계)

- 형식: OpenAI 콘솔 사용량 CSV(Activity) + OpenAI 콘솔 비용 CSV(Cost, 하루 합계) · 집계 줄 18
- 요청 991건 (AI 제공사가 센 수, num_model_…)
- 청구 금액(비용 CSV): $3.12, 7일 (2026-10-01 ~ 2026-10-07). 모델·키별로 나뉘지 않은 하루 합계입니다.
- 기간 2026-10-01 ~ 2026-10-07 · 모델 2개
- 호출 하나하나가 아니라 AI 제공사가 묶어 센 값입니다(가장 촘촘한 것이 1분 묶음). 본문·요청은 없습니다.
- 로그는 이 컴퓨터 밖으로 나가지 않았습니다. 진단기는 아무것도 보내지 않습니다.
- **이 파일로 볼 수 있는 것**: 출력이 청구서에서 차지하는 비중 · 모델별 토큰과 금액 · 캐시 읽기 비율 · 시간대 몰림 · 써 놓고 못 읽은 캐시의 하한 · 캐시 최소 길이 미달 신호(요청 수가 있는 파일) · OpenAI Flex 로 보낼 수 있는 비중의 상한(4절).
- **호출 로그를 주시면 볼 수 있는 것**: 비용 증가 요인(재전송·출력 제한으로 중단된 응답·접두 흔들림·캐시 적중)과 추가 최적화 기회(캐시 최소 미달·호출끼리 공통 접두부·변경된 부분만 변경 부분만 생성·기존 응답 재사용). AI 제공사 집계에는 호출 하나하나가 없습니다. 호출 로그를 남기려면 README 의 "이 파일이 아직 없다면" 을 보세요.

## 2. 입력·출력 비용 구성

- 출력 금액 $1.14 / 전체 $3.12 = **36.4%** (모델 2개 중 2개, 청구서로 역산한 단가와 단가표 2026-10-25)
- gpt-synth-mini: 청구서만으로 단가를 냈습니다 — 입력 $0.40 · 출력 $3.00 / 100만 토큰, 캐시 읽기 0.10배. 모델 하나만 쓴 날 3일 중 2026-10-04·2026-10-06 로 풀고 나머지 1일로 맞춰 봤습니다(가장 큰 차이 0.0%).
- 청구서 대조(7-6): 모든 모델에 단가가 있는 7일 — 계산 $3.12 · 청구 $3.12 · 차이 0.0%.
